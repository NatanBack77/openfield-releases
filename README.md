# Openfield — Releases

Downloads oficiais do [Openfield](https://github.com/NatanBack77/openfield):

- **Linux**: `openfield-x86_64.AppImage` — `chmod +x` e execute (requer webkit2gtk-4.1).
- **Windows**: instalador NSIS (`*-installer.exe`) ou executável portátil.

O aplicativo verifica e instala atualizações automaticamente a partir das releases deste repositório (painel de atualizações no canto superior direito).
